# Real-Time Chat Moderation: from TF-IDF to a quantized BERT

SWE015 homework, Use Case 4. An English chat app labels each message **clean / offensive**, shows how confident it is, masks offensive messages and logs how long each prediction took on CPU. The app uses the **INT8-quantized BERT** by default, and you can switch to any other model in the side panel.

## Quick start

Requires **Python 3.12** (newer versions may lack wheels for some packages).

```bash
git clone https://github.com/Nurasln/chat-moderation-ladder.git
cd chat-moderation-ladder
python -m venv .venv
.venv\Scripts\activate            # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

**Run (single command):**
```bash
streamlit run app.py
```
On first start the trained models (~630 MB) are downloaded from the Hugging Face Hub
([Nurlss/chat-moderation-models](https://huggingface.co/Nurlss/chat-moderation-models)) into `models/`.
Then open http://localhost:8501 and type a message.

## The four models (same held-out test set)

| # | Model | Technique area |
|---|-------|----------------|
| 1a | Regex normalization + edit-distance lexicon matcher (rule baseline) | B · Classical NLP |
| 1b | TF-IDF (1-2 grams) + Logistic Regression | B · Classical NLP |
| 2 | Word2Vec trained on our training messages + feedforward network (SGD + backprop) | A · Neural networks |
| 3 | `bert-base-uncased` fine-tuned for classification (WordPiece tokenizer) | C · Transformers |
| 4 | Model 3 with dynamic INT8 quantization, CPU (**used in the app**) | D · Efficient models |

## Results

Test set: 860 messages. Metric: macro-F1 (the classes are imbalanced: 72% clean). Latency: one message at a time on CPU, end to end (normalize → model → probability), mean of 300 runs after 10 warm-up runs.
Hardware: Intel Core i7-13650HX (20 logical cores), 32 GB RAM, Windows 11, torch 2.11. BERT was trained on an RTX 4060 Laptop GPU, but **all latencies are CPU only**.

See [results/results_table.md](results/results_table.md) (generated by `src/benchmark.py`), per-model scores in `results/metrics/`, every test prediction in `results/predictions/`, and the quantization experiments in [results/quantization_experiments.md](results/quantization_experiments.md).

## Reproduce everything

```bash
python -m src.data              # download TweetEval "offensive", save train/val/test CSVs
python -m src.train_classical   # model 1a + 1b
python -m src.train_nn          # model 2
python -m src.train_bert        # model 3 (GPU recommended, ~3 min on RTX 4060)
python -m src.quantize          # model 4 + CPU test scores of models 3 and 4
python -m src.benchmark         # results table: macro-F1, size, latency
```
To train BERT on an NVIDIA GPU, install the CUDA build of torch first:
`pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128`.

## Project layout

```
app.py                  Streamlit chat app
src/config.py           paths, labels, seed, Hugging Face repo id
src/data.py             dataset download + splits
src/normalize.py        regex normalization (leetspeak, repeats, masking tricks)
src/edit_distance.py    Levenshtein distance (hand-written dynamic programming)
src/lexicon.py          offensive-word lexicon built from training data + fuzzy matcher
src/train_classical.py  models 1a / 1b
src/nn_model.py         averaged Word2Vec vector + feedforward network
src/train_nn.py         model 2
src/train_bert.py       model 3
src/quantize.py         model 4
src/predictors.py       one predict_proba() interface for all models (used by app + benchmark)
src/benchmark.py        results table
src/evaluate.py         shared metrics
src/download.py         fetch model files from the Hugging Face Hub
```

## Data
TweetEval `offensive` = OffensEval 2019 (SemEval-2019 Task 6), English tweets, loaded from
[cardiffnlp/tweet_eval](https://huggingface.co/datasets/cardiffnlp/tweet_eval). Official splits: train 11,916 / validation 1,324 / test 860.

- Zampieri et al. (2019). *SemEval-2019 Task 6: Identifying and Categorizing Offensive Language in Social Media (OffensEval).*
- Barbieri et al. (2020). *TweetEval: Unified Benchmark and Comparative Evaluation for Tweet Classification.*
- Devlin et al. (2019). *BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding.*
